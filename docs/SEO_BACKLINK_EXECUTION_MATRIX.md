## 1. Compliance & Anchor Diversification Rules

1. **Strict Zero-Wholesaler Hard Constraint:**  
   IntriHub operates as an on-demand direct-to-site digital marketplace and material provider. The word **"wholesaler"** must NEVER be used in any directory listing, profile, guest article, anchor text, or post. Always use terms like **"Material Provider"**, **"Direct Supplier"**, **"Sourcing Platform"**, or **"Procurement Partner"**.
2. **Anchor Text Diversification Rule:**  
   Do NOT use the exact same anchor text on more than two external domains for any single URL. Distribute link equity across:
   - **Exact Match:** Targeted product + locality (e.g., `vitrified tiles material provider Bengaluru`)
   - **Partial Match:** Natural conversational phrasing (e.g., `sourcing vitrified tiles in Bengaluru from IntriHub`)
   - **Branded:** IntriHub + locality/category (e.g., `IntriHub Bengaluru Tiles`)
   - **Generic / URL:** `https://intrihub.com/vitrified-tiles-material-provider-bengaluru` or `explore materials on IntriHub`
3. **Canonical Consistency:**  
   Always link directly to the primary HTTPS URL without trailing slashes.

## 4. Google Search Console URL Inspection & Submission SOP

For each of the 22 URLs:
1. Navigate to **Google Search Console** > Select property `https://intrihub.com` (or Domain property).
2. Paste the full canonical URL (e.g., `https://intrihub.com/vitrified-tiles-material-provider-bengaluru`) into the top **URL Inspection** search bar.
3. Click **Test Live URL** to confirm:
   - HTTP 200 response
   - Googlebot smartphone user-agent rendering success
   - Zero structured data errors (verify `LocalBusiness`, `BreadcrumbList`, `FAQPage`, and `ItemList` schemas pass)
4. Click **Request Indexing**.
5. Log the timestamp and inspect again 48 hours later to verify the URL appears in the Index Coverage report as "URL is on Google".
