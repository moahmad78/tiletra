## 🎯 1. Core Mandate & Routing Rule (Strict Instruction)

> [!IMPORTANT]
> **RULE #1: 100% HOMEPAGE REDIRECTION / DESTINATION RULE**
> - Target Destination URL: **ALWAYS** `https://intrihub.com`
> - **ZERO** internal sub-page routing (`/shop`, `/product/`, `/categories` etc. are strictly prohibited for this campaign).
> - Every backlink injected across all 50 anchor keywords links directly to the root homepage (`https://intrihub.com`).

## ⚖️ 2. Backlink Distribution & Equity Split

- **Total Anchor Text Keyphrases:** 50
- **DoFollow Links:** **30 Links (60%)** — Injected for high link-equity transfer on Web 2.0 authority posts, guest articles, and directory profiles.
- **NoFollow Links:** **20 Links (40%)** — Injected across community discussions (Quora, Reddit, Medium, Forums) to emulate a natural backlink profile.
